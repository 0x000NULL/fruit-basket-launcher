FIG · Fruit Basket No. 4
PS1 emulator. One of the first fruits ever grown, for the first PlayStation.
Cut across, a fig is a disc packed with seeds. Drawn sharp at any size.

COLOURS
  Paper F4EFE3   Ink 1A1A1A    Seed C8322A
  Night 141414   Cream EDE6D6  Night seed E5483C

WORDMARK
  Archivo ExtraBold (wght 800) at 72% width (wdth 72), capitals.
  Text in the SVG wordmarks and lockups is outlined, so no font is needed.

USE
  Red is only ever the seeds: points, never a fill.
  Below 32 px, use the -small mark (six big seeds round the hollow, heavier skin).
  -night files are for dark backgrounds.
  The mark shows only where no game is: app icon, site, empty library.
