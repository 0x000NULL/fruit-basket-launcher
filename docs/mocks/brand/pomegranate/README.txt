POMEGRANATE · Fruit Basket No. 1
PS2 emulator. Seeds on the inside: drawn sharp at any size, never as pixel art.

COLOURS
  Paper F4EFE3   Ink 1A1A1A    Seed C8322A
  Night 141414   Cream EDE6D6  Night seed E5483C

WORDMARK
  Archivo ExtraBold (wght 800) at 72% width (wdth 72), capitals.
  Text in the SVG wordmarks and lockups is outlined, so no font is needed.

USE
  Red is only ever the seeds: points, never a fill.
  Below 32 px, use the -small mark (three seeds, heavier skin).
  -night files are for dark backgrounds.
  The mark shows only where no game is: app icon, site, empty library.

FILES
  logo/         mark, wordmark and lockup as SVG; logo/png/ has the lockups at 2x
  icons/        pomegranate.ico (16-256) and pomegranate-favicon.ico (16-48)
  icons/png/    paper icons 48-512, night icons 128-512, favicons 16-48
  art/          pomegranate-disc.svg, the disc label from the empty library
  boards/       the mockups at 2560 x 1600
